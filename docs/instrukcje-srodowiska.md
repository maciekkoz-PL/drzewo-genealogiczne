# Instrukcje środowiska badań genealogicznych

To środowisko służy badaniom genealogicznym rodziny Marysi, nie uruchamiaj aplikacji ani badań bez zlecenia. Używaj istniejącego repozytorium /workspace/drzewo-genealogiczne; każda sesja jest izolowana, nie twórz dodatkowych worktree bez wyraźnej prośby.
Na początku przeczytaj README.md, git status i dotychczasowe zapisane wyniki/historię badań. Zachowaj zmiany użytkownika. Dokumentuj źródła dokładnymi URL, sygnaturami i datą dostępu; oddzielaj fakty, hipotezy i sprzeczności. Nie utożsamiaj osób jedynie po nazwisku. Przy zleconych badaniach zapisuj ustalenia i historię w repozytorium, aby kolejne sesje mogły je odtworzyć.
Python 3.12: pypdf 6.10.0, pdfplumber 0.11.9, PyMuPDF 1.26.6, pandas 2.2.3, openpyxl 3.1.5, xlrd 2.0.1, Pillow są dostępne w bazowym środowisku. Sprawdź ich importy. PDF tekstowy odczytuj pypdf/pdfplumber, skany renderuj PyMuPDF. XLSX: pandas/openpyxl; starszy XLS: xlrd (import sprawdzony, rzeczywisty XLS nie testowany). HTTPS i HTML można obsługiwać urllib.request i html.parser bez dodatkowych bibliotek.
OCR: tesseract plik stdout --tessdata-dir /workspace/genealogy-tools/tessdata -l pol+deu+rus+lat. Modele oficjalnego tessdata_fast przypięto do commitu 65727574dfcd264acbb0c3e07860e4e9e9b22185. Domyślny katalog systemowy ma eng/osd. Sprawdź tesseract --tessdata-dir /workspace/genealogy-tools/tessdata --list-langs. Wszystkie 4 modele uruchomiono na syntetycznym obrazie. OCR pisma ręcznego/starych krojów wymaga kontroli wzrokowej i nie jest dowodem sam w sobie.
Brak usług do uruchomienia. Sprawdź dostęp do potrzebnej strony osobnym żądaniem HTTPS z zachowaniem proxy i TLS. Lokalna piaskownica może blokować sieć mimo działającego proxy; stosuj wspierany mechanizm eskalacji. PyPI i odczyt GitHub sprawdzone. Portale archiwalne przy onboardingu zwracały proxy CONNECT 403; domeny zapisano do projektu konfiguracji, ale dostęp wymaga ponownego sprawdzenia po zastosowaniu/publikacji. Nie traktuj zapisanego projektu jako aktywnej polityki. Nie obchodź CAPTCHA, logowania, opłat ani ograniczeń archiwów. Dodatkowe hosty przekierowań/skanów mogą wymagać rozszerzenia listy domen. Nie ma obecnie dostępnego narzędzia wyszukiwarki internetowej ani przeglądarki; HTTP nie zastępuje interaktywnego dostępu do stron JavaScript.
Nie zapisuj sekretów w repozytorium. Nie instaluj nic w plikach śledzonych podczas przygotowania środowiska.

# Drzewo genealogiczne Marysi

Projekt badawczy mający na celu odnalezienie przodków Marysi oraz odtworzenie historii jej rodziny.

Badania prowadzone przy wsparciu OpenAI Codex.

Zasady:
- Każde odkrycie dokumentujemy źródłem i dokładnym linkiem.
- Oddzielamy fakty potwierdzone od hipotez.
- Nie utożsamiamy osób wyłącznie na podstawie podobieństwa nazwisk.
- Zachowujemy historię badań i kopie dokumentów.
- Aktualizujemy drzewo genealogiczne na podstawie zweryfikowanych dowodów.
